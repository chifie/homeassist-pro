# HomeAssist Pro

Create a professional frontend web application called "HomeAssist" using React, TypeScript, Tailwind CSS, and GSAP animations.

HomeAssist is a modern home services platform that helps users find trusted professionals such as electricians, plumbers, cleaners, mechanics, and technicians.

The goal is to create a premium startup-level frontend experience with excellent UI/UX, smooth animations, and responsive design.

Technology Requirements:

- React + TypeScript

- Tailwind CSS

- GSAP for animations

- React Router for navigation

- Modern component-based architecture

Brand Style:

Name: HomeAssist

Theme: Trust, reliability, convenience, professionalism

Design inspiration: Modern SaaS platforms

Feel: Clean, premium, user-friendly, and trustworthy

Create these frontend pages:

1. Landing Page

- Beautiful hero section with an engaging headline:

  "Trusted professionals for your home, whenever you need them."

- Animated service cards using GSAP

- Call-to-action buttons:

  "Find a Service"

  "Join as a Professional"

- Popular services section:

  - Electrical

  - Plumbing

  - Cleaning

  - Repairs

  - Maintenance

- How it works section with animated steps

- Why choose HomeAssist section

- Customer reviews/testimonials

- Professional footer

2. Service Search Page

- Search bar

- Category filters

- Location filter UI

- Professional service cards

- Rating display

- Experience badges

- "View Profile" button

3. Professional Profile Page

- Profile image

- Name and profession

- Skills

- Experience

- Portfolio gallery

- Ratings and reviews

- Contact/request service button

4. User Dashboard UI

- Overview cards

- Recent service requests

- Saved professionals

- Profile settings

5. Professional Dashboard UI

- Profile management

- Service listing

- Customer requests

- Reviews section

- Availability status

6. Login and Register Pages

- Beautiful authentication UI only

- Modern form design

- Smooth animations

Animation Requirements:

- Use GSAP for:

  - Hero text animations

  - Scroll-triggered animations

  - Card reveals

  - Page transitions

  - Hover effects

- Animations should feel smooth and professional, not distracting

UI Requirements:

- Fully responsive (mobile, tablet, desktop)

- Modern typography

- Clean layouts

- Premium cards

- Soft shadows

- Glassmorphism elements where suitable

- Dark/light mode option

- Accessible design

Code Quality:

- Create reusable components

- Organize folders professionally

- Use clean TypeScript practices

- Avoid duplicated code

- Make the project look like a real production startup website

The final result should feel like a real HomeAssist product ready for users, not a beginner practice project.
